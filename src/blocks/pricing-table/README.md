# BW Pricing Table

## Description
A responsive row of pricing plan columns. Each column is a BW Pricing Column block so plans can be added, removed, reordered, and edited independently.

## Features
- Ships with three equal-width pricing columns
- Add or remove plan columns with the appender button
- Columns stretch to equal height
- Wraps gracefully on narrow screens
- Works with the standard block alignment controls

## Attributes
- `htmlId` (string) — Optional element ID
- `extraClass` (string) — Optional extra CSS class

## Usage
Add the Pricing Table block, then edit each BW Pricing Column child for the plan name, price, features, and button. Select a column and enable "Highlight" to mark a plan as featured.

## Accessibility
- Uses standard block editor inner block structure
- Each column keeps native heading, list, and link semantics

## Browser Support
All browsers supported by the block editor.
