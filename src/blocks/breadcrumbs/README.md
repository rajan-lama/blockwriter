# BW Breadcrumbs

## Description

Displays an accessible breadcrumb trail for the current page. The trail adapts
to the queried content type and is built on the server, so it stays accurate
when the permalink or taxonomy structure changes.

The block renders nothing on the front page and shows a sample trail while
editing.

## Features

- Home link with an optional custom label.
- Parent pages for hierarchical content.
- Category ancestry for posts.
- Taxonomy ancestry for hierarchical terms.
- Author, search, post type archive, date archive, and 404 labels.
- Configurable separator and current-page visibility.
- `aria-label`, `aria-current`, and `aria-hidden` on the separator for
  screen readers.

## Attributes

- `separator` (string) — Character shown between items. Default `›`.
- `showHome` (boolean) — Show the home link.
- `homeLabel` (string) — Label for the home link. Falls back to "Home".
- `showCurrent` (boolean) — Show the current page as the last item.
- `htmlId` (string) — Optional wrapper ID.
- `extraClass` (string) — Optional extra wrapper class.

## Usage

Place the block near the top of a single post, page, or archive template.
The trail is generated by `src/blocks/breadcrumbs/render.php`.

## Accessibility

The wrapper is a `<nav>` with an `aria-label`. The final item uses
`aria-current="page"` and is not linked. Separators are marked
`aria-hidden="true"`.

## Browser Support

Modern evergreen browsers.
