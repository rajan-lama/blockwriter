# BW Logo Grid

## Description
A responsive grid of client, partner, or sponsor logos. Logos display in grayscale and return to full color on hover, giving a clean trust-bar effect.

## Features
- Add as many logos as needed from the media library
- Click any logo to replace it; remove logos individually
- Choose 2 to 6 columns
- Optional grayscale-to-color hover effect
- Columns adapt on tablet and mobile
- Responsive with full-width and wide alignment

## Attributes
- `logos` (array) — Logo items with url, id, and alt
- `logoColumns` (number) — Number of columns (2-6)
- `grayscale` (boolean) — Grayscale styling until hover
- `htmlId` (string) — Optional element ID
- `extraClass` (string) — Optional extra CSS class

## Usage
Add the Logo Grid block and click Add Logo to insert logos. Use the columns setting to control how many logos appear per row.

## Accessibility
- Each logo keeps its alt text
- Replace buttons have accessible labels

## Browser Support
All browsers supported by the block editor.
