# BW Spacer

## Description

Add vertical space between blocks to improve the visual rhythm of your layout.

## Features

- Adjustable height from 0-600px
- Collapse button to quickly remove space
- Standard advanced options (position, visibility)

## Attributes

- `spacerHeight` (number) — Height in px (default: `50`)
- `htmlId` (string) — Optional ID attribute for the wrapper
- `extraClass` (string) — Optional extra CSS class(es) for the wrapper

## Usage

Insert the BW Spacer block where you need breathing room between content and adjust its height in the inspector.

## Accessibility

The spacer is rendered with `aria-hidden="true"` and provides no information, so it is not announced by assistive technologies.

## Browser Support

All modern browsers.
