# BW Lead Capture

## Description

A configurable multi-field form for capturing leads. The form submits directly
to a form or CRM endpoint supplied by the site owner; BlockWriter does not store
submissions.

## Features

- Configurable field list with add, edit, and remove controls.
- Field types: text, email, phone, URL, and multi-line message.
- Per-field label, name, placeholder, and required flag.
- Optional heading, description, and consent text.
- Configurable form endpoint and submit method.
- Server-side validation of field names and types.

## Attributes

- `heading` (string) — Form heading.
- `description` (string) — Supporting copy.
- `fields` (array) — List of field objects:
  - `label` (string) — Visible label.
  - `name` (string) — Form field name.
  - `type` (string) — `text`, `email`, `tel`, `url`, or `textarea`.
  - `placeholder` (string) — Placeholder text.
  - `required` (boolean) — Whether the field is required.
- `buttonText` (string) — Submit button label.
- `actionUrl` (string) — Provider form endpoint.
- `method` (string) — `post` or `get`.
- `consentText` (string) — Optional small print.
- `htmlId` (string) — Optional wrapper ID.
- `extraClass` (string) — Optional extra wrapper class.

## Usage

1. Insert the **BW Lead Capture** block.
2. Open the block settings and paste the form **Action URL** from your form or
   CRM provider.
3. Add, edit, or remove fields as needed. Field names must match the names your
   provider expects.
4. Publish and submit a test lead.

Markup is generated by `src/blocks/lead-capture/render.php`. Field names are
restricted to letters, numbers, `_`, `-`, and `[]`, and field types are limited
to the allow list above.

## Accessibility

Each field has a visible label associated by `id`. Required fields use the
native `required` attribute, and textareas use multiple rows for comfortable
completion.

## Browser Support

Modern evergreen browsers.
