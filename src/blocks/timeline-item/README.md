# BW Timeline Item

## Description
A single dated entry used inside the Timeline block. Each item shows an
optional date label above a free-form block content area.

## Features
- Editable date label shown in uppercase accent styling
- Open content area for composing any blocks
- Marker dot and spacing drawn automatically from the parent timeline

## Attributes
- `itemDate` (string) — Date or short heading shown above the content
- `htmlId` (string) — Custom HTML id attribute
- `extraClass` (string) — Custom CSS class name

## Usage
Only valid inside the Timeline block. Set the date label and add blocks such as
heading, text, or buttons to describe the milestone.

## Accessibility
Date labels are rendered as regular text. The content area is keyboard
accessible through standard block editing behavior.

## Browser Support
All browsers supported by the modern WordPress block editor.
