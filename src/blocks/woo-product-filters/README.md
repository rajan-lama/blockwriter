# BW Product Filters

## Description
Displays filters for WooCommerce product archives: product category links and a
min/max price form. Useful on shop pages and product category sidebars.

## Requirements
- WooCommerce must be active. The block is only registered when WooCommerce is
  available.

## Features
- Product category links (ordered by name, limited to a configurable count)
- Optional product counts per category
- Marks the currently viewed category with `aria-current="page"`
- Min/max price form that submits `min_price` and `max_price` to the shop page
- Clear filters link back to the shop page
- Renders nothing when WooCommerce or the `product_cat` taxonomy is unavailable

## Attributes
- `title` (string) — Optional heading above the filters
- `showCategories` (boolean) — Show category links
- `categoryLimit` (number) — Maximum number of categories (1-50, default 8)
- `showCounts` (boolean) — Show the product count beside each category
- `showPrice` (boolean) — Show the price filter form
- `priceMin` (number) — Pre-filled minimum price
- `priceMax` (number) — Pre-filled maximum price
- `buttonText` (string) — Price form submit label
- `htmlId` (string) — Custom HTML id attribute
- `extraClass` (string) — Custom CSS class name

## Usage
Place the block on a shop page, a product category archive, or in a sidebar
pattern. Category links point at each term archive and the price form submits
WooCommerce's standard `min_price`/`max_price` query arguments.

## Accessibility
Group titles are rendered as visible labels, price fields have screen reader
labels tied to unique ids generated by `wp_unique_id()`, the current category
is exposed with `aria-current`, and the submit control is a real button.

## Notes
This block is intentionally lightweight. It renders standard links and a plain
GET form rather than depending on AJAX, so it works without JavaScript and does
not need to intercept WooCommerce's archive query.

## Browser Support
All browsers supported by the modern WordPress block editor.
