# BW Steps

## Description
A numbered list of steps for process, onboarding, and how-it-works sections. Each step shows a number badge, a title, and a description.

## Features
- Auto-numbered step badges
- Add, edit, and remove steps from the block settings
- Vertical or horizontal layout
- Empty steps are hidden on the front end
- Full-width and wide alignment

## Attributes
- `steps` (array) — Step items with title and description
- `stepsLayout` (string) — Vertical or horizontal arrangement
- `htmlId` (string) — Optional element ID
- `extraClass` (string) — Optional extra CSS class

## Usage
Add the Steps block and fill in each step title and description under Steps Settings. Choose the horizontal layout for a side-by-side process row.

## Accessibility
- Number badges are decorative with proper aria handling
- Titles use headings and descriptions use paragraphs

## Browser Support
All browsers supported by the block editor.
