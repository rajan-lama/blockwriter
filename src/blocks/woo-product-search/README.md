# BW Product Search

## Description
Displays a search form scoped to WooCommerce products. Submitting the form
searches only the `product` post type, so results stay inside the store
catalog.

## Requirements
- WooCommerce must be active. The block is only registered when WooCommerce is
  available.

## Features
- Product scoped search using a hidden `post_type=product` field
- Optional custom accessible label, placeholder, and button text
- Optional search button
- Uses the standard `woocommerce-product-search` form class so theme and
  WooCommerce styles apply

## Attributes
- `label` (string) — Screen reader label for the search field
- `placeholder` (string) — Placeholder text
- `buttonText` (string) — Submit button label
- `showButton` (boolean) — Show the submit button
- `htmlId` (string) — Custom HTML id attribute
- `extraClass` (string) — Custom CSS class name

## Usage
Insert the block on a shop page, homepage, sidebar, or any content area. The
form submits a standard WordPress search request constrained to products via
the `post_type` query argument.

## Accessibility
The form uses `role="search"`, and the field has a real label with a unique id
generated by `wp_unique_id()`. The label text is visually hidden but available
to assistive technology, and the submit control is a real button.

## Notes
The form action points at `home_url( '/' )` and the current search query is
preserved in the field value. A plain GET form is used so it works without
JavaScript and without depending on third-party AJAX behavior.

## Browser Support
All browsers supported by the modern WordPress block editor.
